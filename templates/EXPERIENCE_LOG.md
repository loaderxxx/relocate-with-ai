# Дневник реального опыта
До фактического действия не отмечать запись как личный опыт.
| Дата | Этап | Ожидание | Что сделано | Фактический результат | Деньги / время | Источник подтверждения | Что можно публиковать |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

К каждой истории добавлять:
- условия случая: страна, основание, месяц, существенные обстоятельства без идентификаторов;
- что было правилом, что ответом специалиста, что личным наблюдением;
- где опыт может не повториться;
- исправления и дата перепроверки.

Нельзя по одному кейсу выводить процент одобрения, средний срок для всех или гарантированную стоимость.
Публичная версия создаётся без паспортов, точных адресов, реквизитов и чужой переписки.
